Парсер архивных тарифов Yota — Windows 10/11 x64

Запустите start.bat и введите начальный и конечный номера тарифов.
Устанавливать Python не нужно. Папку bin переносите целиком вместе с остальными файлами.

Скорость и количество одновременных запросов настраиваются в settings.ini:
requests_per_second — запросов в секунду;
parallel_requests — одновременных запросов.
По умолчанию: requests_per_second = 10, parallel_requests = 3.
top_count — количество тарифов в топе, по умолчанию 25.
Настройки можно менять без повторной сборки.

Результаты сохраняются в results/tariffs.txt. Новые строки добавляются к старым.
После перебора results/top_tariffs.txt содержит до top_count самых дешёвых тарифов.
Для переноса истории скопируйте свой tariffs.txt в папку results.

Пример команды: start.bat --start 350 --end 400 --top-count 10
Пересобрать топ без запросов к Yota: start.bat --top-only --top-count 50

Архивируйте и передавайте всю папку программы самостоятельно.
